# Theme Architecture & Design Tokens

## 1. Five Core Themes
Hindi Assist incorporates five carefully curated visual themes across Web and Android:

| Theme | Purpose | Visual Style |
| :--- | :--- | :--- |
| **Day** | Bright daylight environments | Clean off-white, deep slate text, indigo accents |
| **Night** | Dark low-light environments | Deep navy-slate, ergonomic contrast, cyan glow |
| **Blue** | Professional work mode | Deep sapphire surfaces with light blue accents |
| **Green** | Natural, calming atmosphere | Sage and emerald tones with high readability |
| **Reading** | Eye comfort & reading fatigue | Warm sepia/paper tones with Low/Med/High warmth |

## 2. Reading Mode Modifiers
- **Warmth**: Low (`#faf8f2`), Medium (`#f7f3e8`), High (`#f5eedb`).
- **Contrast**: Normal vs Comfort.
- **Label**: *"Designed for a softer, more comfortable reading experience."*

## 3. Typography and Accessibility Tokens
- Display font: `Outfit`
- Sans-serif body font: `Inter`
- Font scaling: Small, Medium (Default), Large, Extra Large.
- Motion control: Full, Reduced, Off.
