# Hindi Assist — User Guide

## 1. Getting Started
Hindi Assist requires **no user registration or account login**. Core translation operates immediately upon opening the app.

## 2. Using the Android Keyboard
1. Navigate to **Android Settings → System → Languages & Input → Keyboards**.
2. Enable **Hindi Assist Keyboard**.
3. In any messaging app (WhatsApp, Telegram, SMS), tap the input box and select Hindi Assist.
4. Use the top toolbar to switch language pairs (`EN → HI`, `HI → EN`, `TE → HI`, `HI → TE`).
5. Tap `[Clipboard]` to translate copied messages.
6. Type your message and tap `[Insert]` to paste translated text into the field.
7. Tap `[⌨ Switch]` anytime to return to your standard typing keyboard.

## 3. Web & Desktop Walkthrough
1. **Chat Assistant**: Conversational simulation with natural speech bubbles, tone selector, and grammar breakdowns.
2. **Translate Workspace**: Dual-card translator with multi-message context support.
3. **Help Me Reply**: Paste incoming queries to receive 5+ tone-tailored responses.
4. **Learn & Practice**: Master sentence patterns, test yourself before revealing answers, and practice roleplays.
