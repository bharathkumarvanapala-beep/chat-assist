## 3. Lexicon Entry Structure
Each entry contains:
- English word
- Hindi translation with transliteration (e.g., "असल में" - *asal mein*)
- Telugu translation with transliteration (e.g., "నిజానికి" - *nijaanki*)
- Contextual example sentences in English, Hindi, and Telugu
- Conversational usage notes and formality nuances.
