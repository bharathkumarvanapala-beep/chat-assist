# Learning System & Pedagogical Design

## 1. Principles
Hindi Assist is structured to help users gradually reduce dependency on translation and communicate independently.

## 2. Core Modules
- **Explain Like I'm a Beginner**: Breaks down complex aspects (e.g. Present Perfect Continuous, Subject-Object-Verb order) with everyday examples.
- **Sentence Patterns**: Reusable formulas like *"I want to + [verb]"* and *"Can you please + [verb]"* with interactive builders.
- **Mistake Book**: Locally logs repeated errors (e.g., "Yesterday I am going") and provides supportive fill-in-the-blank practice without shaming the user.
- **Word of the Day**: Curated daily word featuring Hindi and Telugu meanings, example sentence, and a quick quiz.
- **Roleplay Practice**: Dialogue simulations (Friend, Grocery Shop, Work Meeting, Interview) generating post-session learning report summaries.
- **Three-Language Bridge**: Side-by-side comparative table showing relationships between English, Hindi, and Telugu.
